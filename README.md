🏙️ HIGH RISE

A thrilling parkour adventure where every jump counts!

Welcome to High Rise, a parkour game made with the Godot Engine. Climb higher, jump across rooftops, overcome challenging obstacles, and test your movement skills as you make your way to the top.

🎮 About the Game

High Rise is a parkour game focused on movement, precision, and exploration. Players must navigate through challenging environments filled with platforms, gaps, obstacles, and dangerous drops.

Your goal is simple: Reach the highest point without falling!

✨ Features
🏃 Smooth parkour movement.
🦘 Challenging jumps and platforming.
🏢 Rooftop-inspired environments.
🎯 Obstacles that test your precision and timing.
🌆 Vertical level design.
🎮 Built using the Godot Engine.
🕹️ Controls
Key	Action
W	Move Forward
A	Move Left
S	Move Backward
D	Move Right
Space	Jump
Shift	Sprint
Esc	Pause

Controls may vary depending on the game's current implementation.

🛠️ Built With
Engine: Godot Engine
Language: GDScript
Genre: 3D Parkour / Platformer
Platform: PC
🚀 Getting Started
Requirements
Godot Engine 4.x
A computer capable of running Godot games
Running the Project
Clone or download this repository.
Open Godot Engine.
Select Import.
Navigate to the downloaded project folder.
Select the project.godot file.
Press F6 to run the current scene or F5 to run the main project.
